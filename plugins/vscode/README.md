# kairos VS Code 확장

VS Code의 활동 막대에 kairos 보기를 두고, 남은 일을 보여 주는 확장입니다. 그룹과 문구는 Orca 패널과 같습니다. 그룹은 긴급, 세션, 에이전트 제안, 오늘, 여유 있을 때, 미룬 일, 이전부터 있던 일입니다.

## 화면

줄 앞의 아이콘은 그 일이 올라온 사유(답장, 리뷰, 담당, 일정, 배포, 세션)를 나타냅니다. 마우스를 올리면 전체 제목, 맡길 범위, 항목 ID가 나옵니다. 제목 앞에는 ID를 붙이지 않습니다.

줄에 마우스를 올리면 자주 쓰는 버튼이 나타납니다. 주요 동작(세션 열고 시작 또는 세션으로 이동), 원문 열기, 완료입니다. 나머지 동작은 오른쪽 클릭 메뉴에 있습니다. 나중에, 새 소식이 오면 다시, 배포 때 다시, PR 올리기, 되돌리기가 여기에 있습니다.

`세션 열고 시작`은 맡길 범위가 있는 일에만 나옵니다. 누르면 그 범위를 보여 주는 확인 창이 뜹니다.

그룹의 접힘 상태는 다음과 같이 시작합니다. 사용자가 바꾼 펼침 상태는 VS Code가 기억합니다.

- `여유 있을 때`: 6건 이상 쌓였고 오늘 할 일이 있으면 접힘
- `미룬 일`, `이전부터 있던 일`: 늘 접힘

상태 표시줄과 활동 막대 배지에는 바로 봐야 하는 그룹(긴급, 세션, 제안, 오늘)의 건수가 나옵니다. 긴급이 있으면 상태 표시줄이 오류 색으로 바뀝니다. 처리하는 동안에는 보기 위쪽에 진행 막대가 보입니다.

## 설정

확장은 따로 설정하지 않아도 동작합니다. `config.toml`의 두 값이 동작을 바꿉니다. 자세한 내용은 [설정](../../docs/configuration.md)에 있습니다.

| 설정 | 효과 |
|---|---|
| `[hosts] enabled`에 `vscode` | 알림을 눌렀을 때 Orca를 호출하지 않습니다 |
| `[sessions] host = "git"` | kairos가 만든 worktree에서 `kairos-run`을 VS Code 터미널로 띄웁니다 |

## 동작

확장은 kairos를 `packages/kairos-client`로만 호출합니다. 실행 파일은 `~/Library/Application Support/kairos/current/bin/kairos`이고, 본인 소유이며 다른 사용자가 고칠 수 없을 때만 호출합니다.

화면은 `kairos watch --json`의 신호와 60초 폴링으로 다시 그립니다. 알림을 누르면(`reveal.json`) 해당 항목으로 이동합니다.

세션 시작은 `kairos accept`가 맡습니다. 세션 호스트가 `git`이면 확장이 `kairos-run`을 VS Code 터미널에서 실행합니다. 이때 셸을 거치지 않고 실행 파일과 run ID만 넘깁니다. 세션이 무엇을 하는지는 [에이전트 세션](../../docs/sessions.md)을 보세요.

버튼은 kairos가 준 `actions`의 이름만 참고합니다. 인자는 공용 클라이언트가 새로 만듭니다. 원문 열기는 허용한 호스트의 https 주소만 엽니다.

## 빌드

```sh
npm install
npm run check   # 타입 검사
npm test        # 모델 테스트
npm run package # dist/extension.cjs와 .vsix
```
