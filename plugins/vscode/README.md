# kairos VS Code 확장

활동 막대의 kairos 보기에 남은 일을 보여 준다. 그룹(긴급, 세션, 에이전트 제안, 오늘, 여유 있을 때, 미룬 일, 이전부터 있던 일)과 문구는 Orca 패널과 같다.

## 화면

- 줄 앞의 아이콘은 사유(답장, 리뷰, 담당, 일정, 배포, 세션)를 나타낸다. 마우스를 올리면 전체 제목, 맡길 범위, 항목 ID가 나온다. 제목 앞에는 ID를 붙이지 않는다.
- 줄에 마우스를 올리면 주요 동작(세션 열고 시작 또는 세션으로 이동), 원문 열기, 완료 버튼이 보인다. 나머지 동작(나중에, 새 소식이 오면 다시, 배포 때 다시, PR 올리기, 되돌리기)은 오른쪽 클릭 메뉴에 있다.
- `세션 열고 시작`은 맡길 범위가 있는 일에만 나온다. 누르면 범위를 보여 주는 확인 창을 띄운다.
- `여유 있을 때`는 6건 이상 쌓였고 오늘 할 일이 있으면 접는다. `미룬 일`과 `이전부터 있던 일`은 항상 접힌 상태로 시작한다. 사용자가 바꾼 펼침 상태는 VS Code가 기억한다.
- 상태 표시줄과 활동 막대 배지에는 바로 봐야 하는 그룹(긴급, 세션, 제안, 오늘)의 건수가 나온다. 긴급이 있으면 상태 표시줄이 오류 색으로 바뀐다.
- 처리하는 동안에는 보기 위쪽에 진행 막대가 표시된다.

## 동작

- kairos는 `packages/kairos-client`로만 호출한다. 실행 파일은 `~/Library/Application Support/kairos/current/bin/kairos`이고, 본인 소유이며 다른 사용자가 고칠 수 없을 때만 호출한다.
- `kairos watch --json`의 신호와 60초 폴링으로 화면을 다시 그린다. 알림을 누르면(`reveal.json`) 해당 항목으로 이동한다.
- 세션 시작은 `kairos accept`가 한다. `config.toml`의 `[sessions] host = "git"`이면 kairos가 만든 worktree에서 `kairos-run`을 VS Code 터미널로 띄운다. 셸을 거치지 않고 실행 파일과 run ID만 넘긴다.
- 버튼은 kairos가 준 `actions`의 이름만 참고하고, 인자는 공용 클라이언트가 새로 만든다. 원문 열기는 허용한 호스트의 https만 연다.
- 설정의 `[hosts] enabled`에 `vscode`를 넣으면 알림을 눌렀을 때 Orca를 호출하지 않는다. 넣지 않아도 확장은 동작한다.

## 빌드

```
npm install
npm run check   # 타입 검사
npm test        # 모델 테스트
npm run package # dist/extension.cjs와 .vsix
```
