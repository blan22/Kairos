# 조직 프로필

관리자에게 받은 조직 프로필(`<이름>.toml`)을 이 폴더에 두세요. 형식은 합성 값으로 만든 [`examples/org.toml`](../examples/org.toml)을 참고합니다.

> [!IMPORTANT]
> 조직 프로필에는 회사 도메인, 그룹 캘린더 ID, 저장소 이름이 들어 있어서 공개 저장소에 올리면 안 됩니다. 그래서 git은 이 폴더의 `*.toml`을 무시합니다.

## 프로필 가져오기

- 대화형 `kairos setup`은 이 폴더의 프로필을 번호 목록으로 보여 줍니다.
- `scripts/install.sh --yes`와 `kairos setup --yes`는 묻지 않고 가져옵니다. 단, 실행한 kairos가 들어 있는 저장소의 이 폴더에 프로필이 하나뿐일 때만 그렇습니다.

받은 파일은 지문을 확인하고 관리자가 알려 준 값과 비교하세요. `--sha256`으로 지문을 고정할 수도 있습니다.

```sh
shasum -a 256 <파일>
```

설정 전반은 [설정](../docs/configuration.md)에 있습니다.
