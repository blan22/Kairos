# 조직 프로필

관리자에게 받은 조직 프로필(`<이름>.toml`)을 이 폴더에 둔다. git은 이 폴더의 `*.toml`을 무시한다. 회사 도메인, 그룹 캘린더 ID, 저장소 이름이 들어 있어 공개 저장소에 올리면 안 되기 때문이다.

- `scripts/install.sh --yes`와 `kairos setup --yes`는 실행한 kairos가 들어 있는 저장소의 이 폴더에 프로필이 하나뿐일 때만 묻지 않고 가져온다.
- 대화형 `kairos setup`은 이 폴더의 프로필을 번호 목록으로 보여 준다.
- 받은 파일의 지문은 `shasum -a 256 <파일>`로 확인하고 관리자가 알려 준 값과 비교한다. `--sha256`으로 고정할 수 있다.

형식은 `examples/org.toml`(합성 값)을 참고한다.
